# 第七阶段：企业级功能完善与稳定性验证

## 7.1 知识库精细权限（已完成）

- 新增部门、用户部门关系表。
- 新增知识库的用户、角色、部门授权表。
- 支持 `query`、`contribute`、`manage` 三个权限等级，多项授权同时存在时取最高权限。
- 管理员默认拥有所有知识库的 `manage` 权限。
- 普通用户只能查看和查询已获授权的知识库，不能通过 collection 名称绕过权限。
- 新增部门管理、用户部门归属、知识库授权与撤销接口。
- 新增 Alembic 迁移 `20260804_0003`。
- 升级前已有知识库自动保留普通用户查询权限；新知识库默认仅管理员可见。
- 保留 Streamlit `app.py` 和 `/login`、`/upload`、`/ask` 兼容接口。

## 7.2 会话与持久化审计（已完成）

- 新增问答会话、会话消息和数据库审计日志表。
- 新增 Alembic 迁移 `20260804_0004`。
- 普通用户可以查看、恢复和删除自己的历史会话，不能访问其他用户的会话。
- 问答接口支持继续已有会话，并持久化问题、回答、引用来源、状态和响应时间。
- AI 调用失败时保存失败消息和失败审计，只向前端返回安全提示。
- 关键操作日志写入数据库，管理员可按事件、结果、用户和分页条件查询。
- 管理后台新增审计日志与使用概况页面。
- 用户查询页新增知识库选择、历史会话、新建会话、恢复会话和删除会话。

验证结果：

- Python 编译检查通过。
- FastAPI、权限、会话、审计和 Alembic 测试：`20 passed`。
- Vue TypeScript 检查和生产构建通过。
- Playwright 桌面端与移动端布局验收通过。

## 7.3 文档生命周期与用户分级管理（已完成）

- 新增文档版本和索引任务数据表，并通过 Alembic `20260804_0005` 迁移历史文档为 V1。
- 上传新版本时保留旧文件与元数据，记录版本号、状态、文本块、失败原因和创建人。
- 首次上传、上传新版本与重新索引均记录任务状态、耗时、文本块和失败原因。
- 管理端展示当前版本、版本列表、索引任务记录与失败详情，并支持上传新版本。
- 新增 `super_admin` 角色；启动时配置的引导管理员自动升级为超级管理员。
- 超级管理员可管理全部账号，普通管理员只可创建、禁用、重置、删除和恢复普通用户。
- 删除用户采用软删除，保留文档、问答历史和审计记录；禁止删除自己及最后一个超级管理员。

验证结果：

- FastAPI、权限、用户软删除、文档版本、索引任务和 Alembic 测试：`23 passed`。
- Vue TypeScript 检查和生产构建通过。
- Playwright 管理员、普通用户、用户分级与文档生命周期场景：`4 passed`，已检查桌面端和移动端布局。
